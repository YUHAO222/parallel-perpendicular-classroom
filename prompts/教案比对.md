# 教案 vs 现有配置（dialogues.js）差异表

对照《平行与垂直.docx》（143 行教案）与页面配置 `dialogues.js`（32 个节点）逐条人工核对。
判定口径：教案是权威来源；`say` 是语音口令关键词，老师说教案里的原话必须能命中，否则会落到兜底动画。

## 二、智能体台词偏差（8 处）

| 节点 | 教案原台词 | 现有配置 | 差异性质 |
|---|---|---|---|
| 1-4 | 如果两根金箍棒同时落在地面上，变成两条直线，它们会怎样？ | 同上 **+「俺老孙赌它们要么相交，要么不相交！」** | 多出末句（教案里后面是老师问学生） |
| 2-3 | 我来看看……**第1、2份**答案判断正确，**第三份**答案嘛… | 我来看看……**第一份**判断正确，**第二份**嘛… | **两/三份不一致**（教案选 3 份：对 2 错 1） |
| 4-1 | …两条直线相交成直角，这就是垂直！ | 同上 **+「帅不帅？」** | 多出末句 |
| 4-2 | （教案里"垂足"定义由**老师**揭示，智能体只做动画：交点闪金光、浮现"垂足"二字） | 悟空说：「（揭示垂足）两条直线相交的这个点，就是垂足！」 | **角色越位**：定义由智能体说了，与"定义由老师讲"的防错原则冲突 |
| 4-3 | 我把垂直的两条直线转一转，这样是垂直吗？这样呢？不管怎么转，只要相交成直角，就是互相垂直。 | **俺老孙**把… + **「俺老孙说垂直就垂直！」** | 加了前缀与末句 |
| 5-5 | **他找对了吗？** | 这位同学找出了3组平行线和2组垂线，还差一组垂线，谁能帮他补充？ | **整句不同**（教案是一句开放追问） |
| **5-6** | **教案中没有这个智能体节点** | 俺老孙来！还有一组在这儿呢！ | **多出的节点**（教案环节五在此直接进入第三题） |
| 6-2 | …动手验证很认真。**特别是第三组同学，投屏的答案很有代表性。**建议大家… | 缺"特别是第三组同学…"这一句 | 少一句 |

## 三、建议处理

1. **口令（改 1 行配置就见效，不用重渲染）**：给 1-3 / 2-1 / 2-3 / 3-3 / 4-4 / 6-2 各补上教案原话关键词，并把 2-3 的"两份"改成"三份"。
2. **台词（要重新生成对应视频）**：1-4、2-3、4-1、4-3、4-2、5-5、6-2 共 7 条按教案原文对齐。
3. **待你拍板的两处结构问题**：
   - `5-6`（"还有一组在这儿呢"）教案里没有 → **删除**，还是保留（作为学生答不出时的兜底提示）？
   - `4-2`（垂足）是否改为"悟空只指交点、由老师揭示"，还是维持现状（悟空说定义）？
