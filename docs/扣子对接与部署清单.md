# 《平行与垂直》双智能体课堂 — 使用与现场（课堂）部署清单

## 一、系统如何工作

- 老师语音指挥（或点控制台）→ 播放对应**整屏视频**（角色动作+课件动画+配音已合成）。
- 悟空：动态演示、追问引导、错误诊断；八戒：出题、随堂反馈、点评、分层推送。
- 视频播完自动回到待机循环；投屏干净（控制台收起后只剩一个小按钮）。

## 二、文件结构

```
index.html          课堂播放页（不用改）
dialogues.js        31个触发点配置（口令/角色/台词/动作/课件）
视频拍摄清单.md      每个视频怎么拍（交给制作）
videos/             放34个视频（idle+2兜底+31触发）
assets/             原始形象图（备用）
```

## 三、上课操作

1. 用 **Chrome/Edge** 打开 `index.html`，点「进入课堂」，允许麦克风。
2. 顶部显示“语音聆听中”即可直接说口令；也可点右下角 **☰** 打开控制台，按 6 个环节找对应节点点击（最稳）。
3. 说错/想重放：控制台点「返回待机」后重新触发。
4. 语音识别不稳时，全程用控制台点击即可，不影响课堂。

> 多个“请你追问/请你点评”类口令重名，语音可能命中相邻节点，建议这类用控制台点，保证播对。

## 四、课堂设备

- [ ] 大屏/投影 + 运行 Chrome/Edge 的电脑
- [ ] 麦克风（老师佩戴或讲台麦）；若只点控制台可不用
- [ ] 外放音量适中；视频音从电脑/功放输出
- [ ] 实物展台或手机投屏（展示学生纸笔作品，用系统自带投屏即可）
- [ ] **离线录屏/关键视频备份**：U 盘另存一份，防止电脑或识别异常（对应教案“准备离线录屏备用”）

## 五、课前检查

- [ ] 34 个视频是否齐全、能否正常出声、播完是否回待机
- [ ] 走查关键节点：1-1、1-3、2-1、3-1、4-1、4-3、5-1、5-7、6-1
- [ ] Kiosk 全屏；关闭更新、屏保、睡眠、通知与浏览器弹窗
- [ ] 纯本地视频可离线；语音识别需在线（Chrome），无网就改用控制台点击

## 六、防错（对应教案第十节）

- **教师是第一责任人**：智能体只做演示/点评，不做定义/判断；平行线、垂线、垂足由老师先讲。
- **先学生后智能体**：投屏学生答案→先请学生说理→再播八戒点评。
- 智能体“说错/做错”时：按教案话术纠正（“不是旋转，是向两端延长”等），或直接返回待机重放；并把错误转化为让学生纠错的教学资源。
- 被带偏：“这个问题课后问，现在回到平行与垂直。”
