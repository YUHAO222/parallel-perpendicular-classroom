# 双智能体《平行与垂直》— 视频拍摄/制作清单

共 **31 条触发视频 + 待机 + 2 条兜底 = 34 个文件**。编号与 `dialogues.js` 的 `id` 一一对应。
建议统一规格后再批量制作：

- 格式 **MP4（H.264 + AAC）**，1920×1080 横屏，单条 **3–10 秒**（台词长的可到 12 秒）
- **角色动作 + 课件动画合成在同一条视频里**（页面整屏播放这一条即可）
- 首尾尽量停在接近待机的静止画面，切回待机不跳戏
- 两个角色同一画风（可沿用 `assets/` 的 3D 形象）：悟空配金箍棒、八戒配九齿钉耙
- 音频：智能体配音（可用声音复刻），现场由视频直接出声，无需另接 TTS

> 关键约定：**定义与判断由老师讲**，智能体只做演示、追问、出题、点评；台词已据此写好。

## 环节一 · AI情境导入（4 条）

**1-1 `1-1_wk_intro.mp4`**

- 口令：「孙悟空，请你先来。」

**1-2 `1-2_bj_intro.mp4`**
- 动作：扛钉耙摇摇晃晃从右侧走出，摸肚子，憨笑
- 台词：大家好，我是猪八戒。今天我来给大家出题和点评，俺老猪虽然贪吃，但看答案可认真啦！
- 口令：「猪八戒，你也介绍一下。」

**1-3 `1-3_wk_line_extend.mp4`**
- 课件：金箍棒从屏幕中央出现、发光，向两端缓缓延伸，延伸处金色光效拖尾
- 动作：悟空挥舞金箍棒、随课件变长，火眼金睛发光
- 台词：看俺老孙的！金箍棒，长长长——！同学们看，金箍棒可以向两端无限延伸，这就是直线的特点，厉害吧！

**1-4 `1-4_wk_question.mp4`**

- 台词：如果两根金箍棒同时落在地面上，变成两条直线，它们会怎样？俺老孙赌它们要么相交，要么不相交！
- 口令：「孙悟空，请你提问。」

## 环节二 · 相交与不相交（4 条）

**2-1 `2-1_wk_extend_works.mp4`**
- 课件：三组直线依次亮起向两端延伸（金色光效）；1号相交处闪红光，2号延长到边缘仍不相交
- 动作：悟空挥金箍棒依次指向三组直线，火眼金睛发光，最后双手抱胸
- 台词：俺老孙来也！金箍棒，长——！大家看，1号延长后相交了！2号怎么延长都不相交，气不气人？
- 口令：「孙悟空，请把1号、2号、3号作品中的直线向两端延长。」

**2-2 `2-2_wk_probe_extend.mp4`**
- 动作：歪头、挑眉，金箍棒杵地
- 台词：看起来不相交的直线，延长后一定不相交吗？俺老孙可不这么认为！
- 口令（追问）：建议点控制台此节点

**2-3 `2-3_bj_comment.mp4`**
- 课件：投屏学生判断练习答案
- 动作：八戒扛钉耙从右侧走出，摸肚子，钉耙指向答案
- 台词：大家好，我是猪八戒。我来看看……第一份答案判断正确，第二份答案嘛，俺老猪觉得有点问题，我们一起看看……
- 口令：「猪八戒，请你点评这两份答案。」

**2-4 `2-4_bj_probe_part.mp4`**
- 动作：钉耙指向第二份答案，擦汗，憨笑
- 台词：如果只看到直线的一部分，能判断它们一定不相交吗？
- 口令（追问）：建议点控制台此节点

## 环节三 · 突破“同一平面”（4 条）

**3-1 `3-1_wk_cube_rotate.mp4`**
- 课件：3D立方体缓缓旋转，两个不同面上的直线分别亮蓝光、红光，始终不相交
- 动作：悟空翻筋斗云绕立方体一圈，火眼金睛发光，金箍棒指两条直线；末段双手抱胸、杵地、挑眉
- 台词：俺老孙来也！大家仔细看这两条直线。它们在两个不同的面上，怎么延伸都不相交，但它们不在同一平面内，所以不是平行线！别想蒙俺老孙！
- 口令：「孙悟空，请旋转立方体。」

**3-2 `3-2_wk_same_plane.mp4`**
- 课件：立方体一个面放大，上面两条直线亮绿光、不相交
- 动作：金箍棒指向绿光直线，拔毫毛吹出金光
- 台词：再看这两条直线，它们在同一个面上，不相交，这才是平行线！服不服？
- 口令：「孙悟空，请对比展示同一平面内的两条不相交直线。」

**3-3 `3-3_wk_probe_premise.mp4`**
- 动作：握拳，火眼金睛发光
- 台词：所以，判断平行线，最关键的前提是什么？想好了告诉俺老孙！
- 口令（追问）：点控制台

**3-4 `3-4_bj_remind_plane.mp4`**
- 动作：八戒扛钉耙从右侧走出，摸肚子
- 台词：我提醒大家，说平行时，一定要先想“同一平面内”哦，别像俺老猪一样马虎。
- 口令：点控制台 / 「八戒，提醒一下」

## 环节四 · 建构“垂直”（5 条）

**4-1 `4-1_wk_rotate_90.mp4`**
- 课件：直线绕交点缓缓旋转、角度数值实时显示；到90°数字变金色闪烁，相交处爆火花
- 动作：悟空金箍棒随直线转动；到90°握拳、火眼金睛大放光芒
- 台词：俺老孙来也！大家注意看角的变化。现在，角变成了直角！两条直线相交成直角，这就是垂直！帅不帅？
- 口令：「孙悟空，请把这条直线慢慢旋转。」

**4-2 `4-2_wk_footpoint.mp4`**
- 课件：交点高亮并浮现“垂足”二字
- 动作：金箍棒指向交点，交点闪金光
- 台词：（配合老师揭示）两条直线相交的这个点，就是垂足！
- 口令：点控制台（老师问“这个交点叫什么”后触发）

**4-3 `4-3_wk_rotate_directions.mp4`**
- 课件：垂直两线整体旋转，每45°停一下，角度始终90°，直角符号常亮
- 动作：悟空随方向翻筋斗云、金箍棒飞舞；末段握拳、杵地定格
- 台词：俺老孙把垂直的两条直线转一转，这样是垂直吗？这样呢？不管怎么转，只要相交成直角，就是互相垂直！俺老孙说垂直就垂直！
- 口令：「孙悟空，请旋转不同方向的垂直。」

**4-4 `4-4_wk_probe_direction.mp4`**
- 动作：握拳，金箍棒杵地
- 台词：垂直与两条直线的摆放方向有关系吗？
- 口令（追问）：点控制台

**4-5 `4-5_bj_support_direction.mp4`**
- 动作：八戒扛钉耙出场，摸肚子，擦汗
- 台词：我补充一点，垂直的关键是相交成直角，和方向没有关系哦，猴哥说得对。
- 口令：点控制台

## 环节五 · 分层练习（11 条）

**5-1 `5-1_bj_q1_basic.mp4`**
- 课件：基础层4组直线题板（平行 / 垂直 / 相交非直角 / 不同方向平行）
- 动作：八戒扛钉耙摇晃，钉耙指屏，题板飞出
- 台词：第一题，判断每组两条直线的位置关系，括号里写“平行”或“垂直”；垂直的在图上标出垂足。
- 口令：「猪八戒，请出第一题。」

**5-2 `5-2_bj_comment_q1.mp4`**
- 课件：投屏典型答案，“延长后相交”的一组高亮
- 动作：钉耙指屏，摸肚子
- 台词：第一份答案全对，垂足也找对了！第二份里这组直线其实是相交的，因为延长后会相交。猴哥，你说是不是？
- 口令：「猪八戒，点评第一题。」

**5-3 `5-3_wk_agree.mp4`**
- 动作：悟空从左侧翻筋斗云跳出，金箍棒杵地
- 台词：没错，八戒说得对！
- 衔接：紧接 5-2

**5-4 `5-4_bj_q2_combo.mp4`**
- 课件：长方形等组合图形题板
- 动作：钉耙指屏，题板飞出
- 台词：第二题，在组合图形中找出所有平行和垂直的直线组，并标出垂足。
- 口令：「猪八戒，请出第二题。」

**5-5 `5-5_bj_comment_q2.mp4`**
- 课件：投屏学生标注的组合图形
- 动作：钉耙指向答案，擦汗
- 台词：这位同学找出了3组平行线和2组垂线，还差一组垂线，谁能帮他补充？
- 口令：点评第二题时触发

**5-6 `5-6_wk_find_last.mp4`**
- 课件：屏幕角落最后一组垂线高亮
- 动作：金箍棒指向角落，火眼金睛发光
- 台词：俺老孙来！还有一组在这儿呢！

**5-7 `5-7_bj_q3_maze.mp4`**
- 课件：几何迷宫任务题板（2组平行+2组垂线+至少1个垂足+命名）
- 动作：钉耙指屏，题板出现迷宫图案，憨笑
- 台词：第三题，用平行与垂直的知识设计“几何迷宫”，至少2组平行线、2组垂线、标出1个垂足，再给迷宫起个名字。
- 口令：「猪八戒，请出第三题。」

**5-8 `5-8_bj_praise_maze.mp4`**
- 课件：投屏学生迷宫作品
- 动作：扛钉耙绕场一圈，摸肚子，憨笑
- 台词：这位同学的几何迷宫真有创意！平行垂直都用上了，还很有美感！俺老猪都想进去走一走！
- 口令：请八戒点评迷宫

**5-9 `5-9_wk_praise.mp4`**
- 动作：翻筋斗云绕场，金箍棒飞舞
- 台词：比俺老孙当年大闹天宫还厉害！

**5-10 `5-10_bj_classify_life.mp4`**
- 课件：投屏生活照片，分“平行/垂直”两类
- 动作：钉耙指屏，摸肚子
- 台词：我把大家找的例子分两类：平行有黑板边框、课桌边……垂直有门窗框、日光灯管……
- 口令：「猪八戒，把大家找到的例子分分类。」

**5-11 `5-11_wk_life_examples.mp4`**
- 课件：铁轨、斑马线、窗户横竖框图片，垂足标注
- 动作：金箍棒指屏，火眼金睛发光
- 台词：俺老孙补充，铁轨、斑马线是平行的好例子；窗户横框和竖框互相垂直，交点就是垂足。看，俺老孙也懂数学！

## 环节六 · 总结与作业（4 条）

**6-1 `6-1_wk_summary.mp4`**
- 课件：思维导图（相交/不相交、垂直/平行、a∥b、a⊥b、垂足）
- 动作：拔一把毫毛吹气 → 空中变出思维导图，金箍棒下方旋转
- 台词：同一平面内两条直线分相交和不相交；相交的特殊情况是垂直，不相交是平行。平行线 a∥b，垂线 a⊥b，互相垂直的交点叫垂足。俺老孙可都记住了！
- 口令：「孙悟空，帮我们梳理一下今天的知识。」

**6-2 `6-2_bj_evaluation.mp4`**
- 动作：扛钉耙，摸肚子，憨笑
- 台词：今天大家表现都很棒！分类积极、验证认真，课后多观察生活里的平行与垂直。提醒：垂足是两条互相垂直的直线的交点，一般交点不叫垂足哦。
- 口令：「猪八戒，给大家一个评价。」

**6-3 `6-3_bj_layered_advice.mp4`**
- 课件：分层建议分两栏出现
- 动作：钉耙分层显示建议，擦汗
- 台词：基础薄弱的同学复习“同一平面内”和“垂足”；学有余力的可以继续设计几何迷宫。

**6-4 `6-4_wk_closing.mp4`**
- 动作：从左侧翻筋斗云跳出，金箍棒杵地
- 台词：不会的问俺老孙，包教包会！八戒，你别光顾着吃！

## 制作优先级建议

1. 先做 **1-1 / 1-2 / 1-3**（出场+直线），验证画风、音量、切换是否顺
2. 再做带核心课件的 **2-1、3-1、4-1、4-3、6-1**（本课可视化重点）
3. 其余出题/点评/衔接视频可批量套模板快速产出
4. `idle.mp4` 最后用主场景静帧加轻微动效导出即可
