# 平行与垂直 · 双智能体课堂（孙悟空 + 猪八戒）

小学四年级数学《平行与垂直》（人教版 2024 四上第五单元第一课时）的 **双智能体课堂投屏系统**：
老师用语音口令（或点控制台）触发整屏视频，孙悟空负责**演示与追问**，猪八戒负责**出题与点评**。

## 技术路线

- **MiniMax H3 Ref2VA（全参考模式）**：3 张参考图（仙侠场景 + 悟空正面全身 + 八戒正面全身），
  六段式提示词，中文台词写在 `<d>[Chinese] …</d>` 内**由模型直接合成语音**（无需外部 TTS）。
- **加速版参数**（实测 ~0.85 秒/帧 @1152×640）：`steps=10`、`res_multistep`+`simple`、`shift 12:3`、
  SageAttention + 内存优化补丁、文本编码器 `nvfp4_awq`（15.6GB）。31 段总渲染约 3 小时。
- **帧率必须按配音时长选**：H3 可生成内容量由**帧数**决定（上限 362 帧）。30fps 下 362 帧仅 12.07 秒，
  实测会导致**长台词尾部被截断**；改回 24fps 后同帧数有 15.08 秒，台词才说得完整。
  帧数按 `字数 ÷ 3.2 + 1.2` 秒计算再吸附 `5+17k` 网格。
- 参考图注意：**不要把三视图整张（含 3 个视角）当参考图**，会诱导模型输出"三份角色"，
  应先按列切成单视角再用。

## 质量校验（实测，非估计）

- 35 条产出的台词全部用 **faster-whisper 转写后与教案原文比对**，逐条完整无截断，
  含 6-1（101 字）的尾句「记住了吗？俺老孙可都记住了！」。
- 教案对齐：补齐 6 处失效口令、修正 8 处台词、删除教案中不存在的 5-6 节点、
  4-2（垂足）改为「悟空只指交点、定义由老师揭示」。
- 规格：1152×640 / 24fps / H.264 + AAC，单条 5.2–15.1 秒。

## 已知限制

- 背景是模型照参考图**重新演绎**，非逐像素还原（首帧与参考图 MAD≈51/255）。
- 课件图形（直角符号、a∥b、a⊥b、垂足、思维导图）由模型自由绘制，精确性有限；
  数学准确性要求高的段落（2-1、4-1、4-2、6-1）建议后期图层叠加替换。
