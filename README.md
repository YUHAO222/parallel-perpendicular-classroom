# 平行与垂直 · 智能体课堂

西游主题（悟空 / 八戒）的《平行与垂直》互动课件：28 页 PPT 页序，角色视频 + 内容卡 + 答题分支 + 实时几何层。

## 直接看
- 线上：GitHub Pages（仓库 Settings → Pages）
- 本地：双击 `启动课堂.bat`，或 `python serve.py` 后打开 http://127.0.0.1:8765/

## 玩法
- 点击画面 / 空格 / → 继续；← 上一页
- 语音口令：第N页、环节一~六、下一段、上一段、跳过、第3组相交、第四题错、提交、重播、出题、判对/判错
- 文本页：视频播完后出卡，点击逐条揭示
- 答题页：题板与出题动画同屏；答完播八戒对/错分支，可语音作答或直接跳过

## 结构
- `index.html` 课堂主页面
- `nodes.js` 页面表（页号 / 类型 / 视频 / 几何层）
- `cards.js` 每页内容卡文字与步数
- `style.js` 播放器状态机（含语音）
- `geom.js` Canvas 精确几何层
- `videos/` 角色片段（干净板，图形由代码绘制）

## 最后一页：课堂助教（只答本课）
- 第 28 页卡片下方输入问题（或点建议问题）即可提问，回车发送。
- 范围锁：只答本课内容（平行 / 垂直 / 垂足 / 记法 / 同一平面 / 延长后相交 / 判断方法 / 生活例子）；问别的固定回一句拒答，不展开。
- 线上（GitHub Pages）没有后端，助教用页面内置的本课知识卡作答，标签显示「本课知识卡 · 离线」。
- 本地跑 `serve.py`（配 `deepseek_key.txt` 或环境变量 `DEEPSEEK_API_KEY`）时，同一套前端会自动改走 DeepSeek，标签显示「DeepSeek · 在线」。
