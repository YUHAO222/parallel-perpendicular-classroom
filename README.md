# 平行与垂直 · 双智能体课堂（孙悟空 + 猪八戒）

小学四年级数学《平行与垂直》（人教版 2024 四上第五单元第一课时）的 **双智能体课堂投屏系统**：
老师用语音口令（或点控制台）触发整屏视频，孙悟空负责**演示与追问**，猪八戒负责**出题与点评**。

## 在线试看

开启 GitHub Pages 后：`https://<用户名>.github.io/parallel-perpendicular-classroom/`

## 怎么用

1. 直接打开 `site/index.html`（Chrome/Edge），点「进入课堂」→ 先播开场出场片，随后进入待机。
2. 说口令（如「猪八戒，请出第一题」）自动播对应视频；也可点右下角 **☰** 按环节手动点播（最稳）。
3. 其余节点未放视频时点它黑屏，属正常。

## 技术路线

- 视频由 **MiniMax H3（Ref2VA 全参考模式）** 生成：场景 + 悟空正面 + 八戒正面三张参考图，
  六段式提示词（subject_definitions / summary / retention_analysis / detailed_description /
  overall_soundscape / non_diegetic_music），**中文台词写在 `<d>[Chinese] …</d>` 里由模型直接合成语音**。
- 规格：1344×768 / 24fps / H.264 + AAC，单条 5～15 秒，帧数吸附 H3 的 `5+17k` 网格。
- 加速：`MiniMax H3 Block Cache (T8)` 跳 Block 1–49（实测命中约 10/25 次前向，单步 35–40s → <1s，
  同 seed 输出帧差 MAD≈7.7，近似无损）。
- 注意：**Turbo LoRA 对 pruned INT8 的 Ref2VA 无效**（50 层 adaln 形状不匹配，会被静默跳过），
  低步数输出为欠采样废片，勿用。
