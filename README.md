# 平行与垂直 · 双智能体课堂（孙悟空 + 猪八戒）

小学四年级数学《平行与垂直》（人教版 2024 四上第五单元第一课时）的 **双智能体课堂投屏系统**：
老师用语音口令（或点控制台）触发整屏视频，孙悟空负责**演示与追问**，猪八戒负责**出题与点评**。

## 技术路线

- **MiniMax H3 Ref2VA（全参考模式）**：3 张参考图（仙侠场景 + 悟空正面全身 + 八戒正面全身），
  六段式提示词，中文台词写在 `<d>[Chinese] …</d>` 内由模型直接合成语音。
- **加速版参数**（实测约 0.85 秒/帧，1152×640）：`steps=10`、`res_multistep` + `simple`、
  `shift 12:3`、SageAttention + 内存优化补丁、文本编码器用 `nvfp4_awq`（15.6GB，比 int8 版省显存）。
- **帧率必须按配音时长选**：H3 的可生成内容量由**帧数**决定（上限 362 帧）。
  30fps 下 362 帧只有 12.07 秒，实测会导致**长台词尾部被截断**；改回 24fps 后同帧数有 15.08 秒，
  台词才能说完整。帧数按 `字数/3.2 + 1.2` 秒再吸附 `5+17k` 网格。
- 参考图注意：**别把三视图整张（含 3 个视角）当参考图**，会诱导模型输出"三份角色"；
  应先按列切成单视角再用。
